# 星球推演 · 世界生成器

当前版本：**1.4.0**。在浏览器中推演世界并探索地图，提供 Windows 和安卓版本。两个版本共用 `site/` 中的世界生成与地图代码；安卓应用将资源打包在应用内，可离线使用。

版本包含世界生成和地图探索、文明历史时间线、文化库与宗教库管理。

## 下载安装

在项目的 Releases 页面下载：

- **Windows**：下载并完整解压便携版 ZIP，双击“启动世界生成器.cmd”，使用时保持窗口开启。
- **Android**：下载 APK，在 Android 8.0 或更高版本安装。更新已安装的应用需要使用与旧版相同的签名。

安卓安装包的资源加载已通过资源路径和 AndroidX 加载器测试；尚未在实体安卓设备上完成运行验证。手机上的计算时间和内存占用取决于设备，球体视图需要设备支持 WebGL。

世界和城市数据存储在当前设备的浏览器或应用里，分享安装包不会带上存档。更换设备前请分别导出世界文件及需要保留的城市存档、文化库和宗教库，再在新设备导入；世界导入时会根据种子和设置重新推演。

## 从源码运行 Windows 版

需要 Python 3。进入项目根目录执行：

```powershell
python windows/server.py
```

服务仅在本机监听，默认打开 `http://127.0.0.1:18768/`。使用期间保持窗口开启，关闭窗口即可停止服务。浏览器本地存档与地址及浏览器绑定。

## 构建安卓版本

安装 JDK 17、Android SDK 与 Gradle，具体配置和构建命令见 [安卓构建说明](android/README.md)。源码构建的调试包使用本机调试签名，不能直接覆盖其他签名的现有安装；发布包需要妥善保管并使用自己的签名密钥。

## 构建球体页面脚本

仓库已包含运行所需的 `site/globe/globe-bundle.js`，普通使用无需构建。修改 `site/globe-src/entry.js` 及其依赖后，可安装 Node.js 和 npm，在项目根目录执行：

```sh
npm ci
npm run build:globe
```

构建会覆盖 `site/globe/globe-bundle.js`。构建依赖版本由 `package-lock.json` 固定。使用当前源码构建的脚本与仓库中原有 bundle 的字节不一致；两者均已用测试数据验证球体页面能初始化，但尚未完整验证所有球体功能与显示效果。

## 项目结构

- `site/`：两端共享的网页、世界生成、地图和素材。
- `windows/`：Windows 本地服务启动入口。
- `android/`：安卓 WebView 应用壳、导入导出桥接与构建配置。
