# 星球推演 · 世界生成器

星球推演是一个在本机生成和探索虚构世界的地图工具。通过 21 项设置和种子，程序依次生成星球地形、气候、水系、文明与历史，再以专题地图、球体和时间线展示结果。当前版本为 **1.4.2**，提供 Windows 便携版和 Android 应用，两端共用同一套网页与生成代码。

## 可以做什么

- 在生成向导中选择星球、地质、气候、人口和文明等参数，查看各选项的影响；也可以自定义部分数值和种子。
- 浏览自然、人文与气候专题地图，搜索地点、规划路线、添加标记或修改名称；导出当前地图 PNG。
- 查看球体、星球档案和文明历史时间线，包括国家、人口、制度、思潮与事件等信息。
- 打开城市及周边地图，查看或重新生成城市布局，并单独导入、导出城市存档；使用和编辑文化库、宗教库。

1.4.2 优化性能、道路生成、省界国界、湖泊生成与历史生成，并新增历史地图中的省份信息。更新说明保留 1.4.0 和 1.4.1 公告。

## 运行

Windows 便携版需要完整解压 ZIP，双击“启动世界生成器.cmd”，使用期间保持启动窗口打开。源码运行需要 Python 3，在仓库根目录执行：

```powershell
python windows/server.py
```

服务只监听本机 `http://127.0.0.1:18768/`；关闭窗口即可停止。浏览器需支持 JavaScript、Web Worker 和 Canvas，球体视图还需要 WebGL。

Android 应用支持 Android 8.0（API 26）及以上版本，将站点资源打包在应用内。安装包的签名、资源完整性与包信息已校验；1.4.2 尚未完成 Android 模拟器或实体设备上的安装与运行验证，性能和兼容性因设备而异。覆盖更新旧安装需要相同的应用签名。

## 保存与数据

世界列表、改名和标记保存在当前浏览器或应用的本地存储中，与设备、浏览器和访问地址绑定；清除应用数据或浏览器数据可能将其删除。请定期导出世界文件，并按需要分别导出城市存档、文化库和宗教库；安装包本身不包含用户保存的世界。

世界文件保存生成设置、种子、文化与宗教库快照、改名和标记，**不保存完整世界网格或渲染后的地图**。打开文件或已保存世界时需要重新推演；旧版本文件会按当前版本的规则重新推演，结果可能与旧版不同。城市布局与世界文件分别保存。浏览器支持文件系统访问接口时，可以选择并关联世界文件位置；其他环境通过下载或系统文件保存流程导出。

## 项目结构

- `site/core/`：地形、气候、水文、文明、行政区与历史推演；`worker.js` 负责生成、地图查询和渲染请求。
- `site/app/`：生成向导、世界列表、地图交互、时间线、文化与宗教库和移动界面。
- `site/city/`、`site/citygen/`：城市生成、布局渲染与存储；`citygen/city-maps/` 中的城市是功能示例数据，不是用户世界存档。
- `site/globe/`、`site/globe-src/`：球体页面及其源码；仓库包含运行所需的已构建脚本。
- `windows/`：本机 HTTP 服务入口。
- `android/`：Android WebView 容器、文件导入导出桥接、资源与构建配置。

## 开发与构建

网页运行不需要安装 Node.js。修改球体源码后，如需重新构建脚本，可在仓库根目录执行：

```sh
npm ci
npm run build:globe
```

命令会覆盖 `site/globe/globe-bundle.js`。Android 构建依赖和签名说明见 [android/README.md](android/README.md)。项目不包含发布密钥或用户存档。
